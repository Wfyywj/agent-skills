description: 从已发生的开发任务及验收证据中提炼或修订可复用经验。用于复盘重复问题、记录反例或反馈经验效果；可独立使用，不是六节点必经步骤。
---

把可核实的方法留下来，同时保留它不适用的条件。

- 先读取任务、实际改动和验收记录，区分已发生事实、解释与猜测；没有足够证据时只记录待验证问题，不编造成功案例。
- 查找已有相关经验，优先补条件、反例或纠正原记录；没有值得复用的新信息时不新增经验，不把聊天记录整体保存成规则。
- 使用项目已有模板；未配置时参考 [经验模板](assets/experience-template.md)。写清方法、适用与禁用条件、证据及其代码/环境版本，避免把一次修复推广到所有项目。
- 记录本次采用、调整或未采用的经验 ID 与版本、理由和实际结果；检索到不等于使用过。任务成功不自动证明经验有效，失败也不自动归因于经验。
- 新经验保持待验证；用未参与提炼的新任务核验后，再依据证据限定使用范围。出现反例时提出收窄、修正或停用建议，保留原始证据与版本，不覆盖历史来制造提升。
- 区分行为正确与提效证据，未知成本留空并说明；没有可比结果就不声称提高正确率或节省费用。经验不得改写当前需求、权限或验收标准。
- 在当前授权范围交付候选或修订；任务复盘不自动授权公开内部代码、日志或跨项目复用私有信息。默认不直接改写通用技能或启用候选经验。
